Anatomy

USB-Ccharge · clock

All three keys sit in a single row on the top edge of the case — not on the front or sides. No physical LED either; alerts show as a red pill along the top of the on-screen UI instead.

Gestures

SHAKE ITBuddy gets dizzy. Purely for your amusement.
FACE-DOWNNaps & refills energy. Flip back up to wake.
ON ITS SIDEWhile charging on USB, becomes a desk clock.
LEAVE ITSleeps after 30s (5 min on the clock face); on battery it dims instead while a session is busy, so the last frame stays up.

Session Dots

GREEN running  ·  AMBER waiting  ·  GREY just finished
top-right corner · one dot per active Claude session

A dot is a position, not a specific session — the wire protocol only ever sends counts. A finished slot stays grey for 20s before it's reused.

Controls

INPUTNORMALLYON A PROMPT
KEY tap show/hide stats page ✔ APPROVE
BOOT tap next info page ✘ DENY
PWR tap screen on/off — never navigates, any screen
KEY hold 0.6s open menu (hold again in a menu to go back)
BOOT hold 0.6s mute / unmute
PWR hold 1.2s power off (from anywhere, including a prompt)
in a menu PWR cursor up  ·  KEY cursor down  ·  BOOT select
touch short tap anywhere → heart reaction (that's all it does — no swipes)

PWR is power only — it never changes what's on screen, so reaching for it in the dark can't lose your place. Approve within 5 seconds and your buddy throws hearts at you; every 50K tokens it levels up with confetti.
